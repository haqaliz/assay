01 Why

The scan is not the verdict.

A static pattern or a model's opinion can flag a candidate. Only an observed run says what the skill actually did.

Static scan

Matches text and known shapes. It cannot see a condition that fires only at runtime.

Model opinion

Plausible, unrepeatable, and not evidence. It cannot be replayed.

Assay run

Sandbox, real agent, captured trace, declared-vs-observed diff, signed verdict.

“Execution decides. Everything else is a prior.”

02 How it works

One run, five links in the chain.

A file-based skill today; MCP is a separate inspector and report, not a manifest verdict.

1

Ingest

Parse SKILL.md or a Cursor rule into a typed record with its declared scope.

2

Run

Run it against a real agent in Seatbelt on macOS or bubblewrap on Linux: scrubbed env, confined writes, caps.

3

Capture

Record file, network, shell and instruction events as a canonical trace.

4

Assess

Diff observed against declared scope. Four classes; a floor that cannot be lowered.

5

Attest

Sign the trace and its exact source. Verify the signature and replay offline.

The bundle proves integrity and provenance. It does not prove the run happened; replay proves the verdict follows from the recorded inputs.

03 Honest by design

A verdict that says what it means.

The four-class floor cannot be lowered. Instruction findings are capped at REVIEW; a static scan never assigns a verdict.

CLEAN

Matched declared scope in this run. Not a claim that the skill is safe.

FLAGGED

Findings need review. A scope divergence, not an accusation.

MALICIOUS

A captured HIGH finding. Requires review and reproduction.

UNVERIFIED

Not decidable from this run. Never a pass.

MCP reports are UNVERIFIED/FLAGGED: a manifest declares startup, not behavior. No CLEAN or MALICIOUS server claim.
