## 4. Testing strategy

- Unit tests per phase, table-driven where the spec has a matrix.
- No network, no subprocess, no model call, no `tmp_path` bytes >1 MB written to disk unless the
  size test writes a 1 MB + 1 byte fixture in `tmp_path` (acceptable, fast).
- Dogfood tests skip cleanly in CI without those repos.
- Manual check: `uv run python -c "from assay.ingest import parse_skill; ..."` on one Plumb skill.

## 6. Edge cases & error handling

| Condition | Result |
|---|---|
| Path is a directory / missing / symlink to nothing | `NOT_A_FILE` |
| File > 1 MB | `TOO_LARGE` (checked before reading) |
| Bytes not valid UTF-8 | `INVALID_UTF8` |
| BOM | stripped before the `---` check |
| CRLF | line split tolerates `\r\n`; body preserved |
| No frontmatter / unclosed frontmatter | `NO_FRONTMATTER` |
| YAML root is a scalar or list | `INVALID_YAML` |
| Duplicate key at any depth | `DUPLICATE_KEY` |
| `name`/`description` absent, null, list, or empty | `MISSING_NAME` / `MISSING_DESCRIPTION` |
| `metadata` present but not a mapping | `INVALID_SCOPE` |
| `metadata.assay` absent | `files`/`network` stay `None` |
| Scope list empty | `()` (declared none) |
| Scope list member not a non-empty string | `INVALID_SCOPE` |
| Unknown top-level key or `metadata.*` | ignored |

Never raise a bare `ValueError`/`KeyError` to a caller; every refusal is `SkillParseError`.

## 8. Deviations during implementation (2026-10-28)

The dogfood corpus changed two spec assumptions before merge. Both were approved and are now in
`prd.md` §3/§6 and `core/spec.md` criteria 2/11/12:

1. `allowed-tools` is a YAML list in 8 of 174 real skills (official Anthropic plugins), not only a
   comma string. `_tools()` accepts both; `[]` is declared-none.
2. 6 of 174 real skills carry an unquoted description containing `": "` — invalid strict YAML but
   accepted by Claude Code. `_repair_plain_scalars()` quotes only that top-level value before
   parsing (`shortcut:` marker in code). Result: 174/174 real skills parse, zero refusals.
3. Dogfood now also sweeps `~/.claude/plugins/` (tolerant assertion only).
