## Phase 4 — Push, CI, merge

1. Push the branch; open the PR.
2. Watch the PR's CI run (`gh run list --branch feat/release-ci/aliz`; `gh run watch <id>`).
3. If green, merge and clean up (worktree/branch). If red, fix the workflow/tests and re-run; do not
   merge a red CI.
4. No tag, no PyPI publish.

## Testing strategy

- Local: `uv run pytest` (916 + version test), `uv run assay --version`, YAML parse.
- CI: the PR run is the proof; the sandbox/ssh-keygen tests are the canary.
- No model/network; no secrets.

## Edge cases & error handling

| Case | Expected |
|---|---|
| Metadata unavailable | The package is installed by uv; if not, the CLI import fails at startup — not expected |
| `assay check --version` | Unknown arg → exit 2 (not required) |
| macOS runner lacks `sandbox-exec` | CI red; fix/pin the runner before merge |
| CI slow | 20-minute timeout; cache |
| No tag/PyPI | Only `Unreleased`; no release claim |
| CI red | Do not merge; fix the workflow/tests |
