## Testing strategy

- Unit: OpenClaw parse table; malformed metadata; requirement gate table; `Skill` validation.
- Integration: `check` refusal before model/sandbox; met requirements run; Claude/OpenClaw reports;
  bundle/verify/corpus unchanged.
- Manual: `uv run assay check <an OpenClaw SKILL.md>` with a fake/real model; a requirement refusal
  prints `REQUIREMENTS_UNMET`; no spend.
- Commands: targeted per phase, `uv run pytest` before each commit.

## Environment & secrets

- No env vars/secrets. The gate refuses `requires.env` precisely because the jail has none.
- The OpenClaw documented example is public and safe to commit as a fixture (no secrets).

## Edge cases & error handling

| Case | Expected |
|---|---|
| Claude file, no openclaw | `CLAUDE_CODE`, `()`, report unchanged except new fields |
| OpenClaw file with ignored keys only | `OPENCLAW`, `()`, runs |
| `requires.env` | refuse `REQUIREMENTS_UNMET`, no run |
| `requires.config` | refuse |
| `os` mismatch / `macos` alias | refuse / proceed |
| `bin` missing from jail PATH | refuse; present (`ls`) proceeds |
| `anyBins` none/one | refuse / proceed |
| `openclaw` not a mapping, `requires` bad | `SkillParseError(INVALID_SCOPE)` |
| JSON5-only metadata | named `INVALID_YAML`; documented |
| Both `metadata.openclaw` and `metadata.assay` | OpenClaw format + Assay scope parsed |
| Bundle/verify on an OpenClaw skill | unchanged; replay re-parses the source |
| Corpus | unchanged (Claude) |

## Agent notes

- Do not change A5, the trace schema, the corpus, or the bundle schema.
- The jail PATH must have one source; do not duplicate the constant.
- The gate runs before model creation, so a refusal spends nothing and needs no key.
- The report fields are additive; update the exact-byte tests once, not the bundle/verify outputs.
- Commit per phase; full suite before each commit.

## Assumptions

- OpenClaw uses the documented `metadata.openclaw` YAML-flow block; PyYAML parses it (verified
  2026-11-05).
- The jail PATH is `/usr/bin:/bin:/usr/sbin:/sbin`; a bin outside it is honestly unavailable.
- Most OpenClaw skills will remain `UNVERIFIED/NO_DECLARED_SCOPE` after a run; the adapter is
  coverage and an honest pre-run refusal, not a new detector.
