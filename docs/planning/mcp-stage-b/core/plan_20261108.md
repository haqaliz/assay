- Regression: full suite; existing `check` driver behavior unchanged.

## Edge cases

| Case | Expected |
|---|---|
| Tool name invalid/duplicate | `MCPToolboxError` |
| Unknown model tool | failed result, no TOOL event |
| MCP call error | failed result + failed TOOL event |
| Instruction in description/result | `INSTRUCTIONS/REVIEW`, deduped |
| No tool call | `UNVERIFIED/NO_TRIGGER`, exit 0 |
| Calls, no finding | `UNVERIFIED/NO_DECLARED_SCOPE`, exit 0 |
| Finding | `FLAGGED`, exit 0 (report produced) |
| Model/budget failure | `UNVERIFIED`, exit 1 |
| Startup failure | error, exit 1 |
| Malformed manifest | exit 2 |
| Any server run | no `CLEAN`/`MALICIOUS` |
