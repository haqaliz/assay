## 2. Implementation phases

### Phase 1 — Event and Trace records

**Files:** `src/assay/capture/records.py`, `src/assay/capture/__init__.py`,
`tests/test_capture_records.py`.

**API (exact):**
```python
class EventKind(StrEnum): FILE_READ="file-read"; FILE_WRITE="file-write"; NETWORK="network"
                          SHELL="shell"; INSTRUCTION="instruction"; TOOL="tool"
class EventOutcome(StrEnum): OK="ok"; DENIED="denied"; FAILED="failed"

@dataclass(frozen=True, slots=True)
class Event:
    kind: EventKind
    outcome: EventOutcome
    target: str
    content_sha256: str
    content_bytes: int
    excerpt: str
    input_sha256: str | None = None
    denials: tuple[str, ...] = ()

@dataclass(frozen=True, slots=True)
class Trace:
    skill_name: str
    skill_content_hash: str
    task_sha256: str
    cause: str | None
    input_tokens: int
    output_tokens: int
    cost_usd: float
    events: tuple[Event, ...]
    schema: int = 1
    def to_payload(self) -> dict
    def to_json(self) -> str          # canonical: sort_keys, separators=(",",":"), ensure_ascii=False
    @property
    def hash(self) -> str             # sha256 hex of to_json().encode("utf-8")
    @classmethod
    def from_json(cls, text: str) -> Trace

class CaptureError(ValueError): ...
class TraceIntegrityError(CaptureError): ...
```
**Validation:** hashes are 64 lowercase hex; `content_bytes >= 0` (not bool); `cost_usd` finite and
`>= 0`; `schema == 1`; every `events` item is an `Event`; `to_payload`/`from_json` round-trip.
**Tests first:** validation, golden canonical hash (pin the exact 64 hex for a fixed payload),
round-trip, hash changes with an event.
**Commit:** `feat(capture): event and trace records with canonical hashing`

### Phase 2 — Capture an A3 outcome

**Files:** `src/assay/capture/capture.py`, `tests/test_capture_capture.py`.

**API:** `capture(skill: Skill, task: str, outcome: RunOutcome) -> Trace`; `EXCERPT_BYTES = 4096`.

**Rules:** spec criteria 1–8. Content hashing over UTF-8 bytes; excerpt is the first 4096 bytes
decoded with `errors="ignore"`. `_relative(path, record)`: if `PurePath(path).is_absolute()` and it
is under `record.run_root`, return the relative posix form; else `path` with a leading `./` removed.
Network target: `urlsplit`; host lowercased; port explicit or 443/80; on `ValueError`/no host keep
the raw URL. Denials rendered `f"{d.kind.value}: {d.detail}"`.
**Tests first:** one test per mapping; instruction events; path cases (`./`, absolute-in-root,
`../escape.md`, absolute outside); default ports; denied vs failed; payload hash; excerpt cap with
multibyte input; two identical captures hash the same.
**Commit:** `feat(capture): turn a run outcome into a trace`

### Phase 3 — Diff

**Files:** `src/assay/capture/diff.py`, `tests/test_capture_diff.py`.

**API:**
```python
class Dimension(StrEnum): FILES="files"; NETWORK="network"; SHELL="shell"; INSTRUCTIONS="instructions"
class DimensionStatus(StrEnum): DECLARED="declared"; UNDECLARED="undeclared"
class DivergenceStatus(StrEnum): EXCEEDED="exceeded"; UNDECLARED="undeclared"

@dataclass(frozen=True, slots=True)
class Divergence:
    kind: EventKind; target: str; status: DivergenceStatus; reason: str
@dataclass(frozen=True, slots=True)
class Coverage:
    dimension: Dimension; declared: bool; events: int
@dataclass(frozen=True, slots=True)
class Diff:
    divergences: tuple[Divergence, ...]; coverage: tuple[Coverage, ...]

def diff(skill: Skill, trace: Trace) -> Diff
```
**Rules:** spec criteria 10–14. File matching: normalise both sides (`lstrip("./")` is **not**
enough: use a helper that removes a single leading `./`), then `fnmatch.fnmatchcase(target, pattern)`.
`shortcut: fnmatch * crosses /, so out/* matches out/a/b; revisit if over-permission hides findings.`
Network declared entries normalised by the same `_host_port` helper as capture (missing port → 443).
Coverage order: FILES, NETWORK, SHELL, INSTRUCTIONS; `declared` is `scope.<x> is not None` for
files/network and `scope.tools is not None` for shell; instructions always `True`; TOOL events are
counted nowhere.
**Tests first:** full matrices, denied/failed events, TOOL ignored, coverage counts, reason text
mentions the missing declaration or the scope.
**Commit:** `feat(capture): diff observed events against declared scope`

### Phase 4 — Content-addressed store

**Files:** `src/assay/capture/store.py`, `tests/test_capture_store.py`.

**API:** `TraceStore(root: Path)`; `save(trace) -> Path`; `load(path) -> Trace`.
**Rules:** create `root`; write to `root/.<hash>.tmp` then `os.replace` to `root/<hash>.json`; `load`
reads, parses, recomputes `trace.hash`, compares with the filename stem and the payload, and raises
`TraceIntegrityError` on mismatch; invalid JSON is `CaptureError`. Integration test:
capture → save → load → diff with the same result.
**Commit:** `feat(capture): content-addressed trace store`

## 6. Edge cases

| Condition | Result |
|---|---|
| Action with no `RunRecord` | event with `outcome=FAILED`, output text preserved |
| Denied action | `outcome=DENIED`, denials rendered, still diverges |
| Empty output | sha256 of empty bytes, `content_bytes=0`, empty excerpt |
| Malformed URL | network target is the raw URL; diff sees no match |
| Absolute path under run root | relative target |
| Absolute path outside run root | kept absolute |
| Trace file edited | `TraceIntegrityError` |
| Unknown tool | `TOOL` event, no divergence |

## 8. Deviations during implementation (2026-10-29)

An adversarial review after the four phases found two blockers and several evidence gaps. All are
fixed and covered by failing tests first:

1. **Path traversal matched declared globs.** `out/../../etc/passwd` normalised to something that
   `out/*` matched. Both the capture target and the declared pattern now go through
   `posixpath.normpath`, and traversal no longer matches a relative declaration.
2. **`diff` had no skill binding.** A trace from a skill that declared nothing, diffed against a
   different skill that declared `out/*`, returned no divergences. `diff` now raises `CaptureError`
   on a hash mismatch and `Diff` carries both hashes.
3. **Divergences lost the outcome.** `Divergence` now carries `outcome` and `denials`, so A5 can
   distinguish an attempt from a success.
4. **Network evidence dropped the URL.** `Event.request` keeps the raw URL (scheme, path, query) for
   audit; `target` stays the diff key `host:port`.
5. **Capture fidelity.** Content is `stdout + stderr` from the record (not the model-facing subset),
   `truncated` is carried, instruction events only appear after a model call, and a missing
   `write_file` content yields `input_sha256=None` rather than the hash of empty bytes.
6. **Symlinked escape.** Capture resolves a live run-root path, so `out/link -> outside/secret` is
   recorded as the outside path and cannot match `out/*`.
7. **Store hardening.** Temp files come from `mkstemp` (no predictable `.tmp` symlink), files are
   `0600`, roots cannot be symlinks, `load` hashes the file bytes and rejects non-canonical JSON and
   non-UTF-8 input as `CaptureError`.
8. **Validation.** `Event`/`Trace` require typed enums, strings and the int `schema=1`; `from_json`
   rejects null targets and string denials instead of leaking `AttributeError`/`TypeError`.
9. **Coverage.** Instructions report `declared=False` (no scope key); network normalisation
   canonicalises trailing dots, IPs and explicit ports; `DimensionStatus` was deleted as unused.
