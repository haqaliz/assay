## Testing strategy

- Unit: manifest forms, selection, refusals, hash; inspect with a fake session.
- Integration: real Seatbelt + fixture; missing command; CLI human/JSON.
- Regression: full suite; no verdict/trace/floor change; no new dependency.
- No model or external network.

## Edge cases

| Case | Expected |
|---|---|
| No `mcpServers` entry selected | `ServerError` lists names |
| Single object, no `--name` | name = file stem |
| `env` with a value | refusal; value not echoed |
| `url` | refusal (`stdio only`) |
| Command not found | report `started=False`, exit 1 |
| Server starts, tools fail | `started=True`, `error` set, exit 1 |
| Timeout | report error, session closed |
| Output | no verdict words; "inspection only" |
| `--keep-run-root` | root preserved; otherwise removed |

- Claude Desktop `mcpServers` is the manifest shape; stdio only.
- `/usr/bin/python3` and `/usr/bin/sandbox-exec` exist on the macOS host.
- The fixture is readable from the jail when copied under `tmp_path` (`/private/var/folders`).
