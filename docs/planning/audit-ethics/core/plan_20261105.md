## Edge cases & risks

| Case | Handling |
|---|---|
| No second reviewer | Keep the audit private; no public finding |
| Author/registry does not respond | Document attempts, escalate to the registry, publish after the window |
| False `MALICIOUS` | Stop, review, correct within 7 days, retract the bundle |
| Active exploitation | 7-day window, registry notified, no unnecessary exploit detail |
| Terms forbid analysis | Do not run; record the exclusion |
| Private records leak | `.assay/audits/` (gitignored) or outside the repo; no third-party content committed |
| The protocol is read as enforcement | Say it is a social gate; the second reviewer is the control |
