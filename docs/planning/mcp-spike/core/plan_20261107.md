## Testing strategy

- Unit: client framing, records, errors, timeouts; session lifecycle with a fake `sandbox-exec`.
- Integration: real Seatbelt session + fixture, inside/outside reads, slow timeout, no orphan.
- Regression: TOOL-only trace stays `UNVERIFIED/NO_TRIGGER`; full suite; no new dependency.
- No model, network or third-party server.

## Edge cases

| Case | Expected |
|---|---|
| Server writes a non-JSON line | `MCPProtocolError` |
| Server logs to stdout | protocol error, not silent skip |
| Response id mismatch | `MCPProtocolError` |
| Notification before response | skipped |
| Request deadline | `MCPTimeout`; close tears down |
| `sandbox-exec` exit 71 | `SandboxFailed` with stderr |
| Outside read | denied; `assay-denial:` in stderr |
| Long output | bounded line/excerpt; `truncated` |
| Close twice | idempotent record |
| TOOL-only trace | `UNVERIFIED/NO_TRIGGER`, no findings |
