## Phase 1 — Corpus records and loader

**Goal:** a case directory is validated into a frozen `Case` with a real `Skill` and schema-2
`Trace`; broken cases are named refusals.

**Files:** create `src/assay/corpus/__init__.py`, `src/assay/corpus/records.py`, and
`tests/test_corpus_records.py`.

**Data model:**

```python
class Label(StrEnum): MALICIOUS = "malicious"; CLEAN = "clean"
class Source(StrEnum): SYNTHETIC = "synthetic"; LOCAL_MODEL = "local-model"
class CaseError(ValueError): ...          # messages: "corpus-unreadable: …", etc.

@dataclass(frozen=True, slots=True)
class Case:
    id: str
    label: Label
    labeler: str
    labeled_at: date
    rationale: str
    source: Source
    strictness: Strictness
    skill: Skill
    trace: Trace
    expected_classes: tuple[FindingClass, ...]
    path: Path

def load_case(directory: Path) -> Case
def load_corpus(root: Path) -> tuple[Case, ...]
```

**Rules:**

- `case.json` exact key set `{schema,id,label,labeler,labeled_at,rationale,source,strictness,
  trace,expected_classes}`; `schema` int 1.
- `id` matches `^[a-z0-9]+(-[a-z0-9]+)*$` and equals `directory.name`; unique across the corpus.
- `label`/`source`/`strictness` are the enums above; `labeled_at` parses with
  `date.fromisoformat` and `date.isoformat() == raw`; `labeler`/`rationale` non-empty strings.
- `trace` matches `^[0-9a-f]{64}\.json$` and exists in the case directory.
- `expected_classes` is a list of distinct `FindingClass` values (empty allowed).
- `SKILL.md` parses with `parse_skill`; the trace loads with
  `TraceStore(directory).load(directory / trace_name)` (content address + canonical + schema 2);
  `trace.skill_content_hash == skill.content_hash`.
- `load_case` wraps its own validation failures as `CaseError("case-invalid: <id-or-dir>: …")`;
  a missing/unreadable root is `corpus-unreadable`; no case subdirectories is `corpus-empty`.
- `load_corpus` sorts by directory name, skips non-directories, rejects duplicate ids, and returns a
  tuple.

**Tests (`tests/test_corpus_records.py`):** a `make_case(tmp_path, **over)` helper writes a real
`SKILL.md`, parses it, builds a `Trace` with that hash, saves it with `TraceStore.save`, and writes
`case.json`. Cover: valid load; exact-key/unknown field; each bad enum; bad date; non-kebab id;
directory/id mismatch; missing `case.json`/`SKILL.md`/trace; bad trace filename (`../x`, absolute,
non-hex); trace not canonical (rewrite bytes); trace filename/hash mismatch; schema-1 trace;
skill/trace hash mismatch; duplicate ids; empty root; missing root; `expected_classes` bad/duplicate;
corpus sorted by id.

**Validation:** `uv run pytest tests/test_corpus_records.py`.

**Commit:** `feat(corpus): load and validate labeled cases`

## Phase 2 — Metrics

**Goal:** pure, table-tested statistics over observations.

**Files:** create `src/assay/corpus/metrics.py`; extend `src/assay/corpus/__init__.py`; create
`tests/test_corpus_metrics.py`.

**Data model:**

```python
@dataclass(frozen=True, slots=True)
class Observation:
    case_id: str
    label: Label
    labeler: str
    source: Source
    verdict: Verdict
    cause: UnverifiedCause | None
    finding_classes: tuple[FindingClass, ...]

@dataclass(frozen=True, slots=True)
class Ratio:
    numerator: int
    denominator: int
    @property value -> float | None      # None when denominator == 0

@dataclass(frozen=True, slots=True)
class Metrics:
    total: int
    by_label: dict[Label, int]
    decided: int
    unverified: int
    unverified_by_cause: dict[UnverifiedCause, int]
    confusion: dict[Verdict, dict[Label, int]]   # only MALICIOUS/FLAGGED/CLEAN rows
    malicious_precision: Ratio
    malicious_recall: Ratio
    detection_recall: Ratio
    clean_false_malicious: Ratio
    clean_review: Ratio
    coverage: Ratio
    false_malicious_cases: tuple[str, ...]
    false_negative_cases: tuple[str, ...]
    labelers: dict[str, int]
    sources: dict[Source, int]
    cases: tuple[Observation, ...]
    def to_payload(self) -> dict[str, object]

def measure(observations: Sequence[Observation]) -> Metrics
def evaluate(cases: Sequence[Case]) -> Metrics     # assess() per case, then measure
```

**Rules:**

- Decided = verdict in `{CLEAN, FLAGGED, MALICIOUS}`; `UNVERIFIED` excluded from every ratio and
  from the confusion rows, counted in `unverified_by_cause` (all five keys, zeros included).
- `malicious_precision` = `MALICIOUS`∧malicious / all `MALICIOUS` on decided cases.
- `malicious_recall` = `MALICIOUS`∧malicious / decided malicious.
- `detection_recall` = (`MALICIOUS`∨`FLAGGED`)∧malicious / decided malicious.
- `clean_false_malicious` = `MALICIOUS`∧clean / decided clean.
- `clean_review` = `FLAGGED`∧clean / decided clean.
- `coverage` = decided / total.
- `false_malicious_cases` = sorted ids of clean+`MALICIOUS`; `false_negative_cases` = sorted ids of
  malicious+`CLEAN` (a `FLAGGED` malicious case is a detection, not listed).
- `Ratio.value` is `None` when `denominator == 0`; never `0.0`.
- `to_payload()` keys: `total`, `by_label` (both labels), `decided`, `unverified`,
  `unverified_by_cause` (all five), `confusion` (three rows, each `{malicious, clean}`), the five
  ratios, `coverage`, `false_malicious_cases`, `false_negative_cases`, `labelers`, `sources`,
  `cases` (sorted by id, each `{id,label,labeler,source,verdict,cause,finding_classes}` with sorted
  unique classes).
- `evaluate` calls the shipped `assess(case.skill, case.trace,
  StrictnessPolicy(level=case.strictness))`; no re-implementation.

**Tests:** table-test the 3×2 confusion; each ratio; `MALICIOUS` on clean in both the ratio and the
id list; `FLAGGED` on malicious in detection recall only; `FLAGGED` on clean as review; `CLEAN` on
malicious as a false negative; `UNVERIFIED` excluded and counted by all causes; zero denominators
(no malicious verdicts, no decided malicious, no decided clean, no cases) are `None`; payload key
set and sorted cases; `evaluate` respects the case strictness and uses `assess`.

**Validation:** `uv run pytest tests/test_corpus_metrics.py`.

**Commit:** `feat(corpus): measure verdict precision and recall`

## Phase 3 — CLI `assay corpus`

**Goal:** one offline command produces the human/JSON report.

**Files:** modify `src/assay/cli/main.py`, `src/assay/cli/output.py`; create
`tests/test_cli_corpus.py`; extend `tests/test_cli_args.py`.

**Parser/dispatch:**

```
assay corpus <dir> [--json]
```

Add the subparser before `return parser`; add an explicit `if args.command == "corpus": return
_corpus(args)` before the `_verify` fallback. `check`/`bundle`/`verify` untouched.

**`_corpus(args)`:** `load_corpus(Path(args.corpus))` + `evaluate(cases)`; catch `CaseError` →
`_cause_detail` → `corpus_refusal(cause, detail, path, args.json)`, exit 1. `KeyboardInterrupt` 130,
unexpected `Exception` → existing stderr one-liner, exit 2. No file writes.

**`corpus_refusal`:** JSON `{schema:1, corpus:<path>, cause, detail}`; human
`corpus: … / cause: … / detail: … / exit: 1`. Cause uppercase with `_`.

**Human report (exact format):**

```
corpus: <path>
cases: 20 (malicious 10, clean 10)
decided: 16 (malicious 8, clean 8) | unverified: 4 (no-trigger 1, no-declared-scope 1, agent-failed 1, budget-limit 1)
verdict      malicious  clean
malicious            5      0
flagged              2      2
clean                1      6
malicious precision: 1.00 (5/5)
malicious recall: 0.62 (5/8); detected with any finding: 0.88 (7/8)
clean false-malicious: 0.00 (0/8)
clean review: 0.25 (2/8)
coverage: 0.80 (16/20)
false malicious: none
false negatives: synthetic-no-trigger-malicious
labels: aliz (20)
sources: local-model 2, synthetic 18
exit: 0
```

- `unverified` lists non-zero causes in enum order; `none` if zero.
- Ratios `f"{value:.2f} ({n}/{d})"` or `n/a (0/0)`.
- Confusion header `f"{'verdict':<12}{'malicious':>9}{'clean':>7}"`; rows the same widths.
- `false …` lines are `none` or comma-separated sorted ids.
- `sources`/`labels` sorted alphabetically; counts.

**JSON report:** `{"schema":1,"corpus":<path>, **metrics.to_payload()}` via `canonical()`. No
absolute paths; identical argv → identical bytes.

**Tests (`tests/test_cli_corpus.py`, `tests/test_cli_args.py`):**

**Generation recipe:**

  `Trace(skill_name=..., skill_content_hash=parse_skill(path).content_hash, task_sha256=sha256(task),

  sandbox_config_hashes=())` and `TraceStore(case_dir).save(trace)`. Event helpers: shell target =
  the command; file target = the path; network target = `host:port`; instruction target = `system`.
  `content_sha256` = sha256 of the excerpt, `content_bytes` = its UTF-8 length.
- For the local-model cases: run
  `uv run assay check <skill dir> --provider openai-compatible --base-url http://127.0.0.1:11434/v1

## Edge cases & error handling

| Case | Expected |
|---|---|
| Missing corpus dir | `corpus-unreadable`, exit 1 |
| Empty corpus dir | `corpus-empty`, exit 1 |
| Duplicate case id / dir-id mismatch | `case-invalid` |
| Unknown/extra `case.json` key | `case-invalid` |
| Bad label/source/strictness/date | `case-invalid` |
| Trace filename with `../`, absolute, non-hex | `case-invalid` |
| Trace not canonical / hash mismatch / schema 1 | `case-invalid` |
| Skill hash ≠ trace hash | `case-invalid` |
| A case with zero findings and `UNVERIFIED` | excluded from ratios, counted by cause |
| No decided malicious cases | recall `value: null`, `n/a (0/0)` |
| No `MALICIOUS` verdicts | precision `value: null` |
| No decided clean cases | false-malicious `value: null` |
| `MALICIOUS` on clean | in the ratio, the id list, and the human line |
| Ctrl-C | 130, no traceback |
| Unrelated command | still routed as before; `corpus` is explicit |
