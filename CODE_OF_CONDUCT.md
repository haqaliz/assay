# Code of Conduct

## Our pledge

We want Assay to be a welcoming, harassment-free project for everyone, regardless of experience,
background, identity, or discipline. Security work benefits from disagreement; it does not benefit
from contempt.

## Our standards

Examples of behavior that helps:

- Being respectful and constructive, especially in code review and disagreement.
- Welcoming newcomers and questions; assuming good intent.
- Focusing on what is best for the project and the people who use it.
- Being explicit about uncertainty; a review finding is not an accusation.

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments, public or private.
- Personal or political attacks, or unwelcome attention.
- Publishing someone else's private information without permission.
- Sharing private audit records, bundles, traces, or credentials without consent.
- Pressuring a reviewer toward a particular verdict.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when representing the
project in public.

## Enforcement

Report unacceptable behavior privately to the maintainer through the contact on the repository
owner's GitHub profile, or use a private GitHub security advisory if you prefer. Reports are handled
confidentially. Maintainers may remove, edit, or reject contributions and comments that violate this
code, and may ban repeat or severe offenders.
